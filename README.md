# BookCraft untuk Android

Muat turun APK daripada [GitHub Releases](https://github.com/keyroul2001-star/BookCraft-Releases/releases/latest). Selepas pemasangan, buka **Tetapan → Semak kemas kini** untuk mendapatkan versi baharu daripada saluran ini.

Projek daripada BookCraft Preview boleh dipindahkan melalui **Simpan sandaran** dalam Preview dan **Pulihkan sandaran** dalam edisi rasmi.
